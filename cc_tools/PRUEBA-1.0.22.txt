CC Tools Dev 1.0.22 — check-in, MakeNow y TitoTB 1.0.18

El error BROWSER_BUSY podía aparecer al ejecutar una tarea mientras la
sincronización automática de recompensas utilizaba el navegador de Dev.
Ahora la tarea espera a que termine esa consulta y reserva su turno. Los
nuevos refrescos quedan aplazados mientras la tarea espera o se ejecuta.
La espera se puede cancelar y está cubierta por el límite de ejecución.

INSTALACIÓN
Detén CC Tools Dev. Descomprime el ZIP y sustituye los archivos de
/addons/cc_tools por los de la carpeta cc_tools incluida. Busca actualizaciones
y pulsa Actualizar en tu instalación existente. Conserva el puerto externo
8088 y la instalación para mantener la configuración, sesión e historial.

PRUEBA
1. Inicia Dev y abre su interfaz para que comience la sincronización automática.
2. Si el check-in de hoy sigue pendiente, ejecútalo mientras se actualizan
   los contadores. Debe esperar y continuar, sin fallar por esa sincronización.
3. Revisa Log: solo debe indicar éxito si el check-in ya estaba registrado
   o Creality Cloud confirma que se ha completado.
4. Si aparece Recordatorio de reposición, Dev debe marcar No recordar de
   nuevo en este ciclo, pulsar Hecho y comprobar o reintentar el check-in.
   Cerrar el aviso por sí solo no se considera éxito.

Activa check-in en una sola de tus instalaciones para esta prueba. El
navegador de TitoTB y el de Dev son independientes. Este ZIP actualiza Dev.

Las pruebas locales usan datos y páginas simulados. Falta comprobar el
flujo completo con tu sesión real de Creality Cloud en Home Assistant.


MAKENOW
Después de actualizar, refresca Historial de puntos para forzar la consulta.
Si Use MakeNow indica 0/1 en Creality Cloud, Dev debe mostrar 0/1 aunque antes
hubiera guardado 1/1. Añadir a la colección mantiene su contador independiente.
Los puntos MakeNow recibidos por aprobación no prueban que se haya usado hoy.
Si no se ha pulsado New Project hoy, se recupera la programación dentro de la
franja configurada cuando se corrige el contador; fuera de ella queda para la
próxima ventana. Puedes comprobarlo también con Ejecutar ahora.
Si ya se intentó hoy, se conserva la protección contra crear otro proyecto.

CAMBIOS DE TITOTB 1.0.18
Base integrada: cf14762 (etiqueta v1.0.18).
- Detección de impresoras con mayor espera y reintento al cargar el Banco de trabajo.
- Los registros de seguimiento no consumen otro turno de impresión.
- Mensaje de pedido disponible en Telegram con enlace al producto.
- Recordatorio de reposición en la lotería y nuevas variantes de texto del aviso.
Se mantiene la recuperación de Dev que marca la casilla, cierra el aviso,
reintenta si hace falta y exige confirmación real del check-in.

VALIDACIÓN

simuladas. Prueba pendiente con tu cuenta real de Creality Cloud y Home Assistant.
